自动执行低风险，Agent 授权范围内
常规补货
覆盖天数 ≤21 天、数量取整到 MOQ 倍数；补货量 = 日均缺口 × 覆盖天数。
边界：覆盖天数 >21 天 → 越界，转审批
小额促销 / 临期折价
折扣 ≤10% 且预算 ≤1 万，且不触碰毛利底线。
边界：折扣 >10% 或预算 >1 万 → 转审批
客服回访任务
针对客诉工单创建回访任务，由门店执行整改。
边界：涉及赔偿的处置 → 转人工
转人工审批高风险，L3 风控审批人决定
促销折扣超过 10%
价格类动作直接影响毛利与品牌定位，必须由人判断。
促销 / 触达预算超过 1 万
预算类动作涉及费用承诺，超出授权额度即转人工。
任何价格变更
价格是竞争与合规双重敏感项，不做自动执行。
跨区域库存调拨
调拨影响两个区域的库存与考核归属，需人工平衡。
直接拒绝L4 禁止动作，策略层拦截
折扣超过 30%
超出正常经营判断区间，直接拒绝并记审计日志。
预算超过 10 万
重大费用支出不属于 Agent 权限范围，直接拒绝。
白名单外的动作
只可调用登记在册的写工具，未登记动作一律拒绝。
为什么拒绝也要写审计
被拒绝的请求同样留痕，事后可回答「谁试图做什么、被什么规则拦住」。
权限等级L0–L4
L0只读
匿名与未授权身份，写入一律拒绝。
L1建议
可查看建议，不可写入。
L2低风险写入
区域经理 / 店长 / 计划员 / 会员运营 / 客服主管 / 总部运营；Agent 服务身份硬上限。
L3高风险写入
风控审批人，唯一可处理高风险审批。
L4禁止
任何身份都不可执行。
Agent 服务身份硬上限为 L2：可自主执行低风险动作，任何高风险动作一律转人工审批，不存在「Agent 自己批自己」的路径；执行阶段 Policy Engine 会再校验一次，构成纵深防御。
