风险规则与授权边界
Policy Engine 消费机器可读规则库；边界写死在策略里，不依赖执行者的自觉
自动执行：低风险，Agent 授权范围内无需人工介入
常规补货
覆盖天数 ≤21 天、数量向上取整到最小起订量倍数；补货量 = 日均缺口 × 覆盖天数。
边界：覆盖天数超过 21 天 → 越界，转审批
小额促销 / 临期折价
折扣 ≤10% 且预算 ≤1 万，且不触碰毛利底线；临期清理按剩余保质期与库存量择折扣档位。
边界：折扣 >10% 或预算 >1 万 → 越界，转审批
客服回访任务
针对客诉工单创建回访任务，任务下发后由门店执行整改。
边界：涉及赔偿的处置 → 转人工审批
转人工审批：高风险，L3 风控审批人决定HITL
促销折扣超过 10%
价格类动作直接影响毛利与品牌定位，必须由人判断是否为短期引流或长期损害。
促销 / 触达预算超过 1 万
预算类动作涉及费用承诺，超出授权额度即转人工，避免 Agent 自主扩大投放。
任何价格变更
价格是竞争与合规双重敏感项，不做自动执行，一律人工确认。
跨区域库存调拨
调拨影响两个区域的库存与考核归属，需人工平衡双方利益。
直接拒绝：L4 禁止动作策略层拦截，不进入审批
折扣超过 30%
超出正常经营判断区间，直接拒绝执行并记审计日志。
预算超过 10 万
重大费用支出不属于 Agent 权限范围，直接拒绝。
白名单外的动作
Agent 只可调用登记在册的写工具，未登记动作一律拒绝执行。
为什么拒绝也要写审计
被拒绝的请求同样留痕，事后可回答「谁在什么时候试图做什么、被什么规则拦住」。
权限等级 L0–L4 与角色分工
L0 只读匿名与未授权身份，写入一律拒绝    L1 建议可查看建议，不可写入
L2 低风险写入区域经理 / 店长 / 供应链计划员 / 会员运营 / 客服主管 / 总部运营    L3 高风险写入风控审批人，唯一可处理高风险审批    L4 禁止任何身份都不可执行
Agent 服务身份硬上限为 L2：可自主执行低风险动作，任何高风险动作一律转人工审批，不存在「Agent 自己批自己」的路径。
