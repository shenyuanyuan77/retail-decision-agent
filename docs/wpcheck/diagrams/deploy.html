一键脚本（推荐）

首次启动自动安装依赖并生成演示数据，约 1 分钟。
Windows：scripts\start.bat
macOS / Linux：bash scripts/start.sh

容器

适用于容器化环境与 CI，无需本机 Python 环境。
docker compose up --build

手动

便于二次开发与调试，可指定数据规模与随机种子。
pip install -r backend/requirements.txt
python scripts/generate.py
python -m uvicorn app.main:app --port 8300

访问入口

控制台 http://127.0.0.1:8300；接口文档 /docs（Swagger UI）。
